Check the fit first.

  • Prepared CSVs with totals for each complete sale and purchase.
  • Explicit purchase links and one currency per matched allocation.
  • No marketplace API connection or automatic matching.
  • Native transaction or line-item exports may need preparation. Renaming a heading alone may not be enough.
  • For eBay, use Order earnings, not Net order earnings, in earnings mode.

Contribution profit is before overheads and income tax. The as-of date labels the supplied snapshot. It does not filter input rows. Later refunds can change the result. No currency conversion.
